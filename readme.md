# Tronerminal Game

Tronerminal is a game of Trone, but played on a terminal. 
There is simple bot that only can see free ways and pick one of them. 
For play comfortable you need to resize your terminal same length and character spacing.

Built for just mood. And even you can set PlayStation joystick. Happy Game!
